# PythonProject

本项目用于记录 Python 与深度学习（Deep Learning）学习过程中的代码实现、实验与实战笔记。

## 目录结构

```text
PythonProject/
├── Deeplearning/
│   └── LiMu/                  # 李沐《动手学深度学习》(Dive into Deep Learning) 学习代码
│       └── 10/                # 10 月练习与实验笔记
│           ├── 1015/          # 1015.ipynb
│           ├── 1016/          # 1016.ipynb
│           ├── 1017/          # 1017_1.ipynb, 1017_2.ipynb, 1017_3.ipynb
│           ├── 1018/          # 线性回归从零实现与简洁实现 (1018linear.ipynb, 1018linear_easy.ipynb 等)
│           ├── 1019/          # Softmax 回归从零开始实现 (1019Softmax.ipynb)
│           └── 1020/          # Softmax 回归与图像分类数据集实战 (1020softmax.ipynb)
└── README.md
```

## 环境要求

- Python 3.8+
- PyTorch
- Torchvision
- Jupyter Notebook / JupyterLab
